# Capri's voice

`af_cortes_tuned.pt` is the voice this fork's Capri uses by default. It's a voice pack for [Kokoro-FastAPI](https://github.com/remsky/Kokoro-FastAPI), tuned from a reference clip with its voice tuner. The clip itself isn't in this repository.

The fork's owner says the clip is generated audio or audio licensed for redistribution. If you think otherwise, please open an issue.

SHA-256: `9a183d7f71a9c5dbea3b83750c7e9cc9e17c13ba80b9f0dca6e7be20514c4100`

The install scripts in [`setup/`](../setup) put it in place for you.
